# Gemma 4 E2B 댓글 모델 외부 데이터 조사

조사 기준일: 2026-09-09

## 결론

홍보 프로그램의 댓글·답글 이력은 새 학습에서 사용하지 않는다. 외부 공개 자료만 사용하되, 공개 데이터라는 이유만으로 블로그 댓글 정답에 바로 섞지 않는다.

현재 확인된 공개 데이터에는 `블로그 본문 + 사람이 쓴 좋은 맞춤 댓글` 페어가 사실상 없다. 따라서 학습을 세 층으로 분리한다.

1. 본문 근거 댓글 SFT: 외부 공개 문서의 재배포 가능한 사실 카드와 별도로 만든 고품질 댓글만 사용
2. 한국어 문체 보조: 라이선스가 명확한 한국어 지시·대화 데이터에서 짧고 자연스러운 응답만 소량 사용
3. 안전성·스팸 판별: 봇 댓글·뉴스 댓글·유해 댓글 데이터는 생성 정답이 아니라 거절 분류기와 평가셋에만 사용

## 제외

- Common Crawl 한국어 웹 원문: 원저작권이 각 사이트에 남고 상업 이용에 원저작자 허락이 필요하다고 명시된 자료는 제외한다.
- 라이선스 미표기 네이버 리뷰·댓글 덤프: 공개 다운로드 가능 여부와 무관하게 제외한다.
- 네이버 블로그 전체 원문 무단 수집: 재배포·학습 허용 근거가 없으므로 제외한다.
- 홍보 프로그램 이력: 사용자의 이번 지시에 따라 전부 제외한다.

## 실제 학습 구성

- 본문 근거 댓글 SFT 2,000건: 생활·육아·여행·맛집·제품·개발·건강·재테크 8개 분야를 균형 구성한다.
- SKIP/거절 500건: 본문 정보 부족, 광고성, 근거 없는 경험담, 위험한 의료·금융 단정, 중복 댓글을 포함한다.
- 문체 보조 1,000건 이하: 외부 한국어 대화 데이터에서 짧고 자연스러운 응답만 추출하며 전체 학습량의 25%를 넘지 않는다.
- 분할은 출처 문서 단위 80/10/10으로 한다. 같은 문서에서 나온 변형 댓글이 학습과 평가에 동시에 들어가지 않게 한다.
- E2B에는 QLoRA로 1차 학습하고, 기본 모델·프롬프트 전용·QLoRA 모델을 동일한 고정 평가셋으로 비교한다.

외부 데이터만으로도 자연스러운 한국어 문체는 개선할 수 있지만, 본문을 정확히 읽고 구체적으로 반응하는 능력은 본문-댓글 페어의 품질이 결정한다. 대규모 일반 댓글을 그대로 넣는 방식은 사용하지 않는다.

## 2026-09-09 연구용 v2 실행 결과

- 외부 공개 검색 문맥 200건을 8개 분야별 25건으로 구성했다.
- 검증 댓글 198건과 사실 부족 `SKIP` 52건, 총 250건으로 E2B QLoRA 1 epoch를 실행했다.
- RTX 5080에서 16 optimizer step, 249.4초가 걸렸고 평균 train loss는 1.8044였다.
- LoRA B tensor 205개가 모두 갱신됐으며 어댑터 크기는 약 96.7MB다.
- 미학습 수동 점검 5건에서 생활·여행·IT·반려동물 문맥은 구체적인 사실에 반응했고, 사실이 없는 건강 문맥은 `SKIP`을 출력했다.
- 아직 독립된 대규모 holdout 평가와 사람 검수를 통과하지 않았으므로 `productionReady: false`다.
