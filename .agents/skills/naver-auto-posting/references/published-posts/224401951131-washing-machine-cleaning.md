# 빨래에서 퀴퀴한 냄새가 날 때, 과탄산소다로 끝내는 세탁조 청소와 통세척 꿀팁

- **Category**: 생활

  2. 드럼세탁기 도어 고무 패킹 틈새 곰팡이와 물때 청소
  3. 세탁 후 도어와 세제함을 활짝 열어 환기 건조하는 세탁실
