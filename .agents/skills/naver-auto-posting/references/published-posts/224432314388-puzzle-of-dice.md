# [프로젝트] Unity 3D 주사위 퍼즐과 Java 실시간 랭킹 서버 풀스택 프로젝트 'Puzzle of Dice'

안녕하세요! 앞서 소개해 드렸던 2D 물리 플랫폼 액션 '마이크 & 밀크박스'에 이어, 이번에는 제가 클라이언트부터 실시간 랭킹 백엔드 서버, 페이스북 소셜 연동까지 풀스택(Full-Stack)으로 개발했던 3D 모바일 캐주얼 퍼즐 게임, 'Puzzle of Dice (Vanish)'의 개발 비하인드와 전체 아키텍처를 10가지 파트로 나누어 자세하게 공유해 드리고자 합니다.

이 프로젝트는 평면적인 2D 매치-3 퍼즐에서 벗어나, 3차원 주사위(Dice)의 회전과 물리적 속성을 퍼즐 룰에 접목한 독창적인 게임입니다. Unity 3D 기반의 퍼즐 메카닉 구현이나 자바 서블릿 기반의 실시간 게임 서버 구축에 관심 있는 개발자분들께 유익한 참고가 될 수 있도록 핵심 아키텍처를 정리했습니다.

1. 프로젝트 개요: 3D 공간을 활용한 실시간 다이스 퍼즐 게임 'Puzzle of Dice'

'Puzzle of Dice(배포명: Vanish)'는 플레이어가 3D 주사위들을 그리드 상에서 굴리고 배치하여, 동일한 눈금이나 연속된 숫자를 조합해 소멸(Vanish)시키는 모바일 캐주얼 퍼즐 게임입니다.

기존 2D 퍼즐 게임들의 단순한 타일 교환 방식을 넘어, 3D 주사위가 굴러갈 때 윗면에 노출되는 눈금의 변화를 계산해야 하므로 고도의 두뇌 플레이와 공간 지각력을 요구합니다. 여기에 3분 동안 제한 시간 내에 최고 점수를 겨루는 '타임어택 블리츠(Blitz)' 룰을 적용하여, 퍼즐 특유의 전략성과 아케이드의 긴장감을 동시에 잡았습니다.

2. Unity 3D 클라이언트 아키텍처: 다이스 롤링과 매칭 소멸(Vanish) 알고리즘

클라이언트 개발에서 가장 심혈을 기울인 부분은 3D 주사위의 직관적인 롤링 메카닉과 매칭 판정 알고리즘의 구현이었습니다.

• 주사위 롤링 & 쿼터니언 회전: 손가락 스와이프 입력에 따라 주사위가 상하좌우로 90도씩 구르는 애니메이션을 쿼터니언(Quaternion)과 회전 행렬(Rotation Matrix)을 활용해 부드럽게 구현했습니다. 굴림이 끝나는 순간 그리드 좌표계에 정밀하게 스냅(Snap)되며 현재 상단 면의 눈금 값을 즉각 갱신합니다.
• 다이스 매칭 & 소멸(Vanish) 판정: 그리드 배열을 순회하며 인접한 주사위 간의 눈금을 검사합니다. 동일한 눈금 3개 이상이 모이거나 스트레이트(1-2-3, 4-5-6 등 연속 숫자)가 완성되면 해당 주사위 그룹에 소멸 플래그를 부여합니다.
• 중력 캐스케이드(Gravity Cascade) & 연쇄 콤보: 소멸된 빈 공간으로 상단의 주사위들이 물리적 바운스 연출과 함께 낙하하며, 이로 인해 연쇄적으로 발생하는 2차, 3차 소멸을 재귀적으로 감지하여 폭발적인 콤보 점수를 부여합니다.

3. 3D 다이스 텍스처와 시각적 타격감을 살리는 파티클 이펙트 시스템

주사위가 소멸될 때의 쾌감을 극대화하기 위해 다채로운 3D 셰이더와 파티클 이펙트 시스템을 설계했습니다.

주사위 눈금마다 고유한 색상 테마와 발광(Emission) 셰이더를 적용하였으며, 연속 콤보가 터질 때마다 화면을 가득 채우는 빛줄기와 파편 파티클이 재생됩니다. 여기에 사운드 피치(Sound Pitch)가 콤보 수에 따라 점진적으로 상승하도록 오디오 믹서를 튜닝하여 시각과 청각을 아우르는 손맛을 극대화했습니다.

4. 초보 유저를 위한 단계별 인터랙티브 튜토리얼 시스템

3D 주사위 굴림이라는 생소한 룰에 유저가 빠르게 적응할 수 있도록 인터랙티브 단계별 튜토리얼을 구축했습니다.

손가락 가이드 애니메이션과 하이라이트 마스크를 통해 주사위를 어느 방향으로 굴려야 눈금이 맞춰지는지 직관적으로 학습시킵니다. 튜토리얼 도중에는 타이머가 정지되며, 각 단계를 통과할 때마다 보너스 코인을 지급하여 긍정적인 플레이 경험을 유도했습니다.

5. 백엔드 아키텍처: Java Servlet과 MySQL을 활용한 실시간 글로벌 랭킹 서버

모바일 퍼즐 게임에서 플레이어의 경쟁심을 자극하고 리텐션을 유지하기 위해서는 정교하고 빠른 랭킹 시스템이 필수적입니다. 이를 위해 자체 Java 백엔드 서버와 MySQL 데이터베이스를 직접 구축했습니다.

• 자바 서블릿(Java Servlet) 경량 서버: Apache Tomcat 환경 위에서 구동되는 순수 Java Servlet 기반 RESTful API를 설계했습니다. 세션리스(Stateless) 구조와 DBCP(Database Connection Pool)를 적용하여 순간적인 대량의 점수 등록 요청에도 병목 없는 초저지연 응답을 보장했습니다.
• MySQL 랭킹 쿼리 최적화: 유저 테이블과 스코어 테이블을 정규화하고, (score DESC, updated_at ASC) 복합 인덱스를 구성하여 수십만 건의 레코드 속에서도 0.01초 이내에 글로벌 1위부터 100위까지의 리더보드를 반환하도록 쿼리를 튜닝했습니다.
• 내 순위 전후 조회(Windowed Ranking): 전체 순위뿐만 아니라 현재 플레이어의 순위를 중심으로 상하 5명의 유저를 슬라이스하여 보여주는 윈도우 쿼리를 구현함으로써 유저가 바로 위의 경쟁자를 추월하고 싶은 동기를 부여했습니다.

6. 소셜 인터랙션: 페이스북 그래프 API 연동과 친구 리더보드

단순한 싱글 플레이 게임에 머물지 않고 유저 간의 자연스러운 유기적 확산(Viral Growth)을 유도하기 위해 페이스북 소셜 플랫폼을 깊이 있게 연동했습니다.

원클릭 페이스북 소셜 로그인과 Graph API 연동을 통해 프로필 사진과 친구 목록을 실시간 동기화했습니다. 전체 글로벌 랭킹 외에도 '내 페이스북 친구들만의 주간 리더보드'를 별도로 제공하여 실제 지인들 사이에서 순위를 뒤집는 재미를 선사했습니다.

7. 스태미너(다이스 하트) 순환 주기와 인앱 상점(Vanish Bank)

모바일 F2P 게임의 핵심인 경제 루프(Core Loop)를 탄탄하게 설계했습니다:

• 스태미너 시스템: 게임 1판당 1개의 주사위 하트가 소모되며, 10분마다 자동으로 1개씩 충전되는 서버 동기화 타이머를 운영합니다.
• 친구 간 무료 선물(Gifting) 시스템: 스태미너가 부족한 플레이어가 페이스북 친구에게 무료 주사위를 선물하거나 요청할 수 있는 비동기 소셜 기프팅 기능을 구현하여, 유저 재방문율을 끌어올렸습니다.
• 상점(Vanish Bank): 게임 머니인 골드와 다이아몬드를 구매하거나 스태미너를 즉시 충전할 수 있는 인게임 뱅크를 구현했습니다.

8. 게임 오버 연출과 신기록 달성 소셜 바이럴 공유

3분 제한 시간이 종료되면 긴장감 넘치는 휘슬 사운드와 함께 최종 스코어가 정산되는 게임 오버 화면으로 전환됩니다.

기존 최고 기록을 경신했을 경우 축하 이펙트와 함께 페이스북 타임라인으로 바로 자랑할 수 있는 오픈 그래프 공유(Social Share) 기능이 작동합니다. 이를 통해 지인들의 호기심을 자극하고 자연스러운 신규 유저 유입 창구 역할을 수행하도록 설계했습니다.

9. 글로벌 원빌드를 위한 다국어 로컬라이제이션 테이블 구축

전 세계 앱스토어 배포를 염두에 두고 개발되었기에, 언어 장벽 없이 플레이할 수 있도록 다국어 로컬라이제이션(Localization) 시스템을 완비했습니다.

인게임의 모든 UI 텍스트는 XML/JSON 기반의 언어 테이블로 분리 관리되며, 기기 설정 언어에 따라 한국어와 영어가 실시간으로 자동 적용됩니다. 특히 알파벳과 한글의 글자 폭 차이로 인해 UI 레이아웃이 깨지지 않도록 동적 폰트 스와핑 및 반응형 앵커 시스템을 NGUI 상에 완벽하게 구축했습니다.

10. 풀스택 개발 회고와 오픈소스 코드 공개

'Puzzle of Dice'는 기획부터 3D 그래픽 연출, 클라이언트 C# 로직, 자바 백엔드 서버, 데이터베이스 설계, 소셜 API 연동까지 게임 개발의 전 과정을 1인 풀스택으로 완수한 값진 프로젝트입니다.

클라이언트의 완성도 높은 손맛과 백엔드의 안정적인 데이터 무결성 검증이 하나로 어우러져 상용 수준의 완성도를 이끌어낼 수 있었습니다.

이번 개발기가 3D 퍼즐 인터랙션 구현이나 자바 서블릿 기반의 실시간 게임 서버 구조를 고민하시는 인디 개발자분들께 유용한 기술적 레퍼런스가 되기를 희망합니다.
