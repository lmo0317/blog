## Published Content

부모님 댁이나 거실 인테리어 소품으로 많은 사랑을 받는 스마트 디지털 액자, 여러분은 어떻게 사진을 넣고 관리하고 계시나요? 

저 역시 가족들과 아이의 예쁜 순간들을 매일 감상하기 위해 카멜(Camel) 스마트 디지털 액자(CPF1010IPS)를 거실에 두고 사용하고 있습니다. 선명한 IPS 화면으로 지나간 추억들을 자동으로 넘겨보는 매력은 정말 좋지만, 한 가지 치명적인 아쉬움이 있었습니다. 바로 '새로운 사진을 액자에 추가하는 과정'이 생각보다 번거롭다는 점이었습니다.

매번 본체 뒤편의 마이크로 SD카드나 USB를 손톱으로 억지로 빼내어 PC에 연결해야 하거나, 전용 클라우드 모바일 앱을 거치자니 고용량 사진 전송 속도가 느리고 사진 정리와 관리가 직관적이지 않았습니다. 특히 PC 하드디스크에 잘 정리해 둔 수십 장의 가족사진을 한 번에 정리해서 액자에 넣기에는 여간 손이 많이 가는 게 아니었습니다.

그래서 직접 만들었습니다. 액자에 손댈 필요 없이, 같은 공유기(Wi-Fi)에 연결된 PC에서 버튼 하나로 사진을 조회하고, 추가·삭제·백업하며, 액자의 모든 환경 설정까지 원격으로 제어할 수 있는 윈도우 데스크톱 프로그램 '카멜 디지털 액자 무선 사진 매니저' 개발 이야기와 상세 기능들을 소개해 드립니다.


1. 개발 배경: SD카드와 전용 앱의 번거로움을 넘어 무선 직결로

카멜 스마트 디지털 액자는 안드로이드(Android) 기반 OS로 구동되며, 로컬 네트워크상에서 무선 디버깅(Wi-Fi ADB) 통신 포트를 지원합니다. 이 원리를 활용하면 복잡한 외부 클라우드 서버나 케이블 연결 없이도, 가정 내 공유기 안에서 PC와 액자 간 1:1 고속 무선 통신 파이프라인을 구축할 수 있습니다.

파이썬(Python)과 세련된 다크 테마 GUI 라이브러리인 CustomTkinter를 기반으로 아키텍처를 설계했습니다. 무엇보다 기술에 익숙하지 않은 사용자라도 편하게 쓸 수 있도록 'Zero-Config 자동 검색' 기능을 넣었습니다. 공유기 내부 IP 대역(192.168.x.x)을 자동으로 스캔하여 카멜 액자의 IP를 단 1~2초 만에 스스로 찾아내어 연결하므로, 복잡한 네트워크 설정 과정이 전혀 필요 없습니다.


2. 핵심 기능: 드래그 앤 드롭 업로드부터 실시간 미리보기까지

프로그램의 메인 화면은 직관적인 2단 분할 레이아웃으로 구성했습니다. 좌측에는 액자에 저장된 모든 사진 목록이 섬네일, 파일명, 용량, 저장 날짜와 함께 표시되며, 원하는 사진을 클릭하면 우측 대형 캔버스에 선명한 미리보기가 나타납니다.

가장 신경 쓴 부분은 파일 전송 편의성입니다. 상단 우측 작업 패널에서 [새 사진 추가] 버튼을 눌러 파일이나 폴더 단위로 한 번에 올릴 수도 있고, 윈도우 탐색기에서 사진이나 폴더를 프로그램 창 위로 끌어다 놓기만 하면 즉시 무선 업로드가 시작되는 '네이티브 드래그 앤 드롭(Drag & Drop)'을 완벽하게 구현했습니다.

백그라운드 스레드 풀(ThreadPool) 기반의 동적 업로드 큐 매니저가 작동하여 대용량 고화질 원본 사진들도 끊김 없이 순차 전송되며, 전송이 완료되는 즉시 안드로이드 미디어 스캐너(MediaScanner)를 트리거하여 액자 화면의 슬라이드쇼가 새 사진들로 자동 갱신됩니다. 또한 소중한 사진들을 PC로 안전하게 내려받는 [선택 사진 PC로 백업]과 액자에서 불필요한 사진을 깔끔하게 지우는 [선택한 사진 삭제] 기능도 모두 지원합니다.


3. 원격 상세 설정: 밝기·볼륨부터 슬라이드쇼 간격까지 원클릭 제어

기존에는 액자의 화면 밝기나 슬라이드쇼 간격을 바꾸려면 액자 본체의 작은 터치스크린이나 리모컨을 눌러가며 번거로운 설정 메뉴를 뒤져야 했습니다. 이제는 PC 프로그램 상단과 우측 패널에 있는 [⚙️ 액자 설정] 버튼 하나로 모든 환경 설정을 팝업창에서 원격 제어할 수 있습니다.

액자의 내부 설정 XML(spUtils) 및 시스템 프로퍼티와 양방향으로 연동되어 다음과 같은 상세 제어가 가능합니다:

• 디스플레이 & 사운드 제어: 슬라이더를 움직여 화면 밝기(10~255)와 스피커 볼륨(0~15)을 실시간으로 조절하고, 화면 자동 꺼짐 절전 시간(항상 켜짐, 10분, 30분, 1시간)을 지정할 수 있습니다.
• 슬라이드쇼 재생 설정: 사진 전환 재생 간격을 5초, 10초, 15초(기본), 30초, 1분, 5분, 30분 중 자유롭게 선택할 수 있으며, 사진 맞춤 방식(화면 꽉 채우기 vs 원본 비율 유지)과 재생 순서(순차 재생 vs 랜덤 셔플)를 원클릭으로 변경할 수 있습니다.
• 리모컨 & 기기 관리 도구: PC에 앉아서 이전 사진/다음 사진으로 화면을 원격으로 넘길 수 있고, 액자의 시계를 PC 현재 시간으로 1초 만에 동기화하는 기능 및 액자 원격 재부팅 기능까지 내장했습니다. 또한 내부 eMMC 저장 공간의 남은 용량을 시각적 프로그레스 바로 한눈에 확인할 수 있습니다.


4. 개발 중 마주친 문제 해결: 유령 미디어 DB 정리와 UI 최적화

프로그램을 고도화하는 과정에서 흥미로운 기술적 이슈들도 해결했습니다. 

첫 번째는 '디지털 액자에 이상한 도표나 검은 화면만 반복해서 뜨는 현상'이었습니다. 원인을 추적해 보니, 과거 기기 테스트나 PDF 문서 조회 과정에서 생성된 수백 개의 유령 미디어 DB 레코드(실제 파일은 삭제되었으나 안드로이드 MediaStore 데이터베이스 인덱스에 남아있던 흔적)가 슬라이드쇼 재생 목록을 오염시키고 있었습니다. 이를 해결하기 위해 실제 사진 파일만 선별하고 유령 DB 레코드 287개를 안전하게 정리한 뒤 재생 프로세스를 재기동하여, 본래 올려둔 가족사진들만 매끄럽게 돌아가도록 완벽히 복구했습니다.

두 번째는 '반응형 UI 레이아웃 최적화'였습니다. 상단 툴바에 자동 검색, IP 입력, 화면 On/Off, 화면 캡처, 새로고침 등 다양한 기능 버튼들을 추가하다 보니, 기본 창 크기(1180px)에서 마지막 [⚙️ 액자 설정] 버튼이 공간 부족으로 숨겨지는 현상이 발생했습니다. 이를 해결하기 위해 전체 위젯 여백과 버튼 크기를 정밀하게 다듬고, 우측 관리 패널에도 별도의 [⚙️ 액자 상세 환경 설정] 버튼을 이중 배치하여 어떤 해상도에서도 편리하게 접근할 수 있도록 UI 접근성을 개선했습니다.


5. 단일 실행 파일 배포와 앞으로의 활용

파이썬이나 ADB 환경이 갖춰지지 않은 다른 가족 구성원의 PC에서도 더블 클릭 한 번으로 실행할 수 있도록, PyInstaller를 통해 모든 통신 바이너리(ADB)와 의존 라이브러리를 하나로 묶은 포터블 단일 실행 파일('카멜액자_사진관리자.exe')로 빌드하여 배포했습니다.

이제 거실 액자 뒤편에 손을 뻗어 카드를 뽑거나 스마트폰 앱으로 답답하게 씨름할 필요 없이, PC에서 소중한 추억이 담긴 사진들을 드래그 한 번으로 액자에 전송하고 완벽하게 관리할 수 있게 되었습니다. 스마트 디지털 액자를 사용하고 계신 분들이라면, 이처럼 로컬 통신 프로토콜을 활용한 자동화 관리 툴을 구축해 보시는 것을 적극 추천드립니다!
