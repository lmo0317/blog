# 🛠️ [기능 명세서] 클라이언트 핵심 기능 구현 명세서

> **문서 코드**: SPEC-04-CLIENT  
> **구현 대상**: 데스크톱 클라이언트 (`apps/engagement`)  
> **핵심 원칙**: 자잘한 옵션 제거, **이웃 새글 자동 댓글 + 스마트 이웃 관리 + 1-Click AI 전자동화**  
> **최종 수정일**: 2026년 9월 6일

---

## 1. 핵심 기능 1: 이웃 새글 실시간 자동 댓글 & 공감 (`FeedList`)

### 1.1 기능 개요
* **경로**: `https://m.blog.naver.com/FeedList.naver`
* **목적**: 내 이웃들이 새로 올린 글을 실시간으로 캐치하여 공감과 AI 맞춤 댓글을 작성함으로써, 내 블로그로의 즉각적인 맞방문과 친밀도를 극대화.

### 1.2 처리 흐름
1. 백그라운드 세션에서 모바일 피드 목록을 주기적으로 로드 (최신 10~20개 새 글 파싱).
2. `logNo`, `blogId`, `title`, `snippet` 추출.
3. **중복 검사**: 로컬 SQLite DB(`feed-history.json`)에서 이미 댓글을 단 게시글인지 확인 후 스킵.
4. **Gemma 4 E2B AI 분석**: 본문 요약 내용을 모델에 전달하여 2~3줄의 따뜻한 맞춤 댓글 생성.
5. 포스팅 페이지 접속 → 공감(❤️) 버튼 클릭 → 댓글 입력 및 등록.
6. **안전 지터**: 네이버 어뷰징 방지를 위해 글당 60초~120초의 랜덤 대기 시간 적용.

---

## 2. 핵심 기능 2: 받은 서로이웃 신청 AI 선별 자동 수락

### 2.1 기능 개요
* **경로**: `https://admin.blog.naver.com/BuddyReceiveManage.naver`
* **목적**: 매일 들어오는 신청 목록에서 스팸/대행사를 AI가 자동 차단하고, 찐블로거만 선별 일괄 수락.

### 2.2 AI 판별 알고리즘
* **1차 텍스트 룰 필터링**:
  * 신청 메시지가 기본 멘트("우리 서로이웃해요~", "서이추 신청합니다")이거나, 상업적 키워드("대출", "보험", "렌탈", "체험단모집", "코인")가 포함된 경우 **자동 거절(Reject)**.
* **2차 Gemma 4 E2B 블로그 분석**:
  * 신청자 블로그 제목과 카테고리를 읽고 정상 활동 블로거 판정 시 **원클릭/자동 수락(Accept)**.

---

## 3. 핵심 기능 3: 오래된 보낸 신청 자동 회수/정리 (500건 한도 보호)

### 3.1 기능 개요
* **경로**: `https://admin.blog.naver.com/BuddyReceiveManage.naver?type=send`
* **목적**: 네이버의 **보낸 서로이웃 신청 500건 대기 한도**에 걸려 신규 이웃을 맺지 못하는 병목을 원천 해소.

### 3.2 동작 로직
1. 내가 보낸 서로이웃 신청 목록을 역순 조회.
2. 신청 날짜가 **7일 또는 14일 이상 경과**한 미수락 대기 건 리스트 추출.
3. `cancelBuddy.naver` API를 안전한 딜레이(2~3초)로 순차 호출하여 일괄 취소.
4. 신청 가능 쿼터 500건을 즉시 회생하여 신규 이웃 소통이 끊김 없이 지속되도록 유지.

---

## 4. 핵심 기능 4: 1-Click AI 전자동 소통 (Auto-Pilot)

* **사용자 입력**: 관심 카테고리(맛집, 육아, 일상 등) 선택 + **[🚀 AI 전자동 시작]** 버튼 클릭.
* **AI의 자율 동작**:
  * 트렌드 키워드 검색 → 상위 랭킹 활동 블로거 탐색 → 광고 블로그 0.1초 자동 컷 → 본문 감정/내용 파악 → 2~3줄 맞춤 댓글 → 공감 → 서로이웃 신청.
  * 하루 최대 100명 한도 도달 시 자동 안전 중단 및 자정 자동 리셋.
