## 1. 한 줄 결론

**돈을 쓰기 전에 "제작자 블로그 실적 글 + 쇼츠"로 신뢰를 만들고, 구매 의도가 가장 높은 크몽에 상품을 올려 첫 유료 고객 10명을 확보한다.** 광고비는 랜딩→체험 전환율이 확인된 뒤(빨라야 60일 이후)에 쓴다. 그 전에 반드시 고칠 것 3가지(가격 미표시, 네이버를 연상시키는 초록 "N" 로고, UTM 미집계)가 있다.

### 2.2 모르는 것 (측정 구멍)

- **다운로드 수**: 설치 파일이 `https://minohlee.mooo.com/updates/neighbormate/NeighborMate-Setup.exe` 직접 링크라 클릭이 집계되지 않는다.

## 3. 포지셔닝과 핵심 메시지

**포지셔닝 한 문장**: 매일 1~2시간을 이웃 관리에 쓰는 네이버 블로거가, 복붙 매크로 댓글과 달리 **글을 읽고 쓴 AI 댓글**로, **AI 요금 없이** 켜두기만 하면 소통이 이어지게 한다.

메인 메시지는 경쟁 제품이 따라 하기 어려운 두 가지로 좁힌다.
1. **"글을 읽고 쓴 댓글"** — 실제 댓글 예시로 보여 준다(형용사 대신 증거).
2. **"월 9,900원, AI 요금 0원"** — 크몽 1위(월 25,000원) 대비 절반 이하(가격 확정 시).

보조 메시지: "켜두면 알아서(자율 주행)", "한 일은 엑셀로 확인", "보안 확인이 뜨면 즉시 멈춤".

| 세그먼트 | 한 문장 | 증거 |
|---|---|---|
| 수익형 블로거 (애드포스트·체험단·쿠팡파트너스) | "한 달 서로이웃 +694명. 이웃 관리에 쓰던 2시간을 글쓰기에 쓰세요." | +694 기록, 엑셀 활동 기록 화면 |
| 블로그 막 시작한 사람 | "이웃 0명에서 시작해도, 내 주제 블로거에게 글 읽은 댓글로 먼저 찾아갑니다." | 황금 키워드 → 소통 연결 화면 |
| 소상공인·병원·학원 담당자 | "직원이 매일 하던 블로그 소통, 사람이 깨어 있는 시간에만 사람 속도로." | 운영 시간·하루 한도·즉시 정지 |
| 블로그 대행사·강사 | "여러 계정·수강생용 묶음 이용권 문의" (B2B는 카톡 1:1로 별도 응대) | — |

- "보호조치 안 걸려요?" → "100% 막는다고 약속할 수 없습니다. 대신 속도·한도·반복을 피하게 만들었고, 보안 확인이 뜨면 바로 멈춥니다."
- "비싸지 않아요?" → "AI가 내 PC에서 돌아 댓글을 몇 개 쓰든 추가 요금이 없습니다."

**시사점**
- 시장가는 **월 2만~3만 원**. 월 9,900원이면 가장 싸다 → "같은 일을 절반 이하 가격에"가 성립한다.
- 대부분 **OpenAI API 키를 사용자가 넣어야** 한다. 로컬 AI로 "API 키·추가 요금 없음"을 내세운 곳은 찾지 못했다. 단, 이웃지기는 판매자가 AI 비용을 대므로 "AI 요금 0원"만으로는 차별화가 약하다 → **가격 + 엑셀 활동 기록 + 받은 신청 AI 선별·이웃 정리까지 한 앱**을 함께 말한다.
- 경쟁자의 주 판매처는 **크몽**, 보조는 자체 사이트 + 카톡 채널 + 유튜브 시연 영상. 우리 채널 순서와 같다.
- 인프런에 "AI 댓글 자동화 프로그램" 강의가 팔릴 정도로 관심이 있다([inflearn](https://www.inflearn.com/course/ai-댓글-자동화-프로그램?cid=332228)).

### 4.2 채널별 규정 확인 결과

- **크몽**: `IT·프로그래밍 > AI 자동화 프로그램`에서 기간제 라이선스 판매가 실제로 이뤄진다(551452, 768025). 그러나 2026-01-05 공지에서 **"검색 순위, 댓글 수 조작 등 여론 조장 매크로"를 금지**하고 완성형 프로그램을 주의 카테고리로 지정했다([posts/770](https://kmong.com/support/expert-center/posts/770)). 위반 시 최고 단계 이용제한. → 상세페이지는 "댓글 수 늘리기"가 아니라 **"이웃 관리 시간 절약·글을 읽고 쓰는 소통"**으로 쓰고, 등록 전 크몽 고객센터에 사전 문의(사용자가 직접)한다. 또 **외부 거래 유도 금지**(연락처 교환·외부 결제 유도 시 최대 365일 제한, [posts/598](https://kmong.com/support/expert-center/posts/598)) → 크몽 상세페이지에 자체 사이트·카톡 링크를 넣지 않는다.
- **네이버**: "광고, 스팸성, 도배 혹은 매크로 등의 어뷰징"은 제재 대상이라고 밝혔다([비즈한국 2025-03-27](https://bizhankook.com/articles/29309.html)). 이용약관 원문·검색광고 심사 조항은 확인 필요(네이버 페이지 접근 불가). "순위 조작"처럼 읽히는 문구는 쓰지 않는다.
- **공정위 추천보증 심사지침(2024-12-01 시행, 2025-12-02 안내서 개정)**: 블로그·카페 글은 경제적 이해관계를 **제목 또는 글 첫 부분**에 표시해야 한다(하단 표시 불인정). 무료 이용권·할인·후기 이벤트 보상도 표시 대상([신&김](https://shinkim.com/kor/media/newsletter/2613), [아주경제](https://www.ajunews.com/view/20251202085042877)). → 제작자 본인 글도 첫 줄에 "제가 만든 프로그램입니다"를 밝힌다.
- **네이버 카페·유튜버**: 검색으로는 카페별 홍보게시판 규정·회원 수, 블로그 유튜버 구독자 수가 거의 확인되지 않았다(확인 필요). 직접 가입해 규칙을 읽는 것이 첫 실행이다.

## 7. 측정 계획

### 7.1 UTM 규칙

모든 외부 링크는 랜딩 홈에 아래 형식으로 단다. 소문자, 공백 대신 하이픈.

```
https://minohlee.mooo.com/neighbormate-app/?utm_source={출처}&utm_medium={유형}&utm_campaign={캠페인}&utm_content={소재}
```

| utm_source | utm_medium | 예시 |
|---|---|---|
| naverblog | content | `?utm_source=naverblog&utm_medium=content&utm_campaign=launch-2610&utm_content=plus694` |
| youtube | shorts | `?utm_source=youtube&utm_medium=shorts&utm_campaign=launch-2610&utm_content=script-a` |
| instagram | reels | `…utm_content=script-b` |
| cafe-{카페영문약칭} | community | `?utm_source=cafe-blogup&utm_medium=community&utm_campaign=launch-2610` |
| kakao | openchat | 오픈채팅 공지 |

- 크몽 상세페이지에는 외부 링크를 넣지 않는다(외부 거래 유도 금지). 크몽 판매는 관리자 페이지의 `kmong` 채널 이용권 발급 수로 잰다.
- `utm_campaign`은 `{주제}-{YYMM}` 형식. `utm_content`는 글·영상 식별자.
- 링크는 스프레드시트 한 장에 "날짜·채널·URL·게시 위치"로 기록한다.

**필요한 코드 수정 (작은 작업 2개)**
1. 랜딩 3페이지의 방문 비콘이 `location.search`의 `utm_source/medium/campaign/content`를 함께 보내고, `visit-service.js`의 `site_visits`에 `utm_source`, `utm_campaign` 컬럼을 추가해 관리자 페이지에 "캠페인별 순방문자"를 보여 준다. 카톡·유튜브 앱 내 브라우저는 referrer가 비므로 UTM이 유일한 단서다.
2. 다운로드 버튼 클릭 시 `page: 'download'` 비콘 1회 전송(`PAGES`에 추가) → 방문 → 다운로드 전환율 측정.
