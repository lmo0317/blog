# 이웃메이트 Pro (Naver Blog Automation Suite)

네이버 블로그의 **서로이웃 자동 추가**, **공감(❤️) & AI 맞춤 댓글 소통**, **핫딜 자동 발행**을 지원하는 윈도우 전용 프로그램입니다.

---

## 📁 프로젝트 폴더 구조

```text
D:\work\dev\blog\
├── 📂 windows/               # 윈도우 전용 독립 실행형 프로그램
│   ├── start.bat             # 윈도우 원클릭 실행 런처
│   ├── server.js             # 로컬 서빙 및 자동화 백엔드
│   ├── lib/                  # VRAM/하드웨어 감지, 모델 매니저, 임베디드 AI, 공감/댓글/서이추 엔진
│   ├── .models/              # 로컬 AI GGUF 모델 보관소
│   └── bin/                  # llama-server.exe 내장 바이너리 폴더
│
└── 🚀 start-windows.bat      # 루트에서 윈도우 프로그램 즉시 실행
```

---

## 🚀 빠른 시작

### 윈도우 프로그램 실행
* **`start-windows.bat`** (또는 `windows/start.bat`)을 **더블클릭**하면 됩니다.
* 내 PC의 GPU VRAM을 자동 감지하고, AI 엔진 및 대시보드가 원클릭으로 구동됩니다.

---

## 🤝 주요 기능 요약

1. **타겟 서로이웃 자동 추가 (노마랩 급 사양)**
   - 키워드 자동 탐색, 최근 활동 블로그 필터링, 자연스러운 소통 멘트, 가변 랜덤 딜레이(15~30초), 중복 방지 및 엑셀(CSV) 다운로드
2. **공감(❤️) & AI 맞춤 댓글 소통 (답방 유도)**
   - VRAM 기반 로컬 AI 모델(Gemma 4 등)을 내장하여 비용 0원으로 본문 및 사진 분석 후 1초 만에 맞춤 칭찬 댓글 작성
3. **알구몬 실시간 최저가 핫딜 TOP 5 자동 발행**
   - 실시간 최저가 딜 수집, 로컬 LLM 블로그 글 작성, 상품 이미지 자동 배치 및 원클릭 스마트에디터 발행
